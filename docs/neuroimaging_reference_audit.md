## 头动 QC 与 FC

| 项目 | 参考脚本 | 本项目当前值 | 原因与科学影响 |
| --- | --- | --- | --- |
| 纳入 run 编号 | QC／FC 默认仅 1–4 | 纳入准备清单中全部正整数 run | 此前为适配不同 run 数而放宽；用户仅指定无 session，并未要求放宽编号范围。出现 run > 4 时会改变 IQR 分布、合格 run 数和 FC，需明确分析范围 |
| QC 样本范围 | XCP-D 成功被试名单 | 准备清单所有被试都完成后拟合 | 为避免自动丢弃失败样本而改变。若成功名单与准备清单相同则一致；否则会影响何时运行 QC，显式缩小清单后也会改变阈值估计人群 |
| FD 与比例精度 | 先保存到 6 位小数，再拟合 QC | 保留浮点精度后拟合 QC | 为避免中间舍入而改变，但不是严格复现；阈值附近的 run 可能得到不同判定 |
| FD 缺失处理 | 不能转换为浮点的值会跳过；可解析的 NaN 会进入均值 | 仅首帧允许缺失，其余非有限或负值报错 | 遵循本项目 AGENTS 的科学错误显式失败规则，避免改变分母而不报告；异常输入的行为不同 |
| FC 无效相关 | `nan_to_num` 将 NaN／Inf 转为 0 | 非有限信号、逐 run 常量 ROI 或无效相关报错 | 遵循禁止静默补零规则，异常数据时会停止。逐 run 常量 ROI 的检查比参考更严格，即使拼接后有方差也会停止 |
| FC 图谱命名 | Schaefer100／200／400，但实际读取完整 4S156／256／456 | 使用真实 4S 图谱名称，并核验 156／256／456 节点 | 澄清命名；未将非皮层节点剔除，图谱信号的选择一致 |
| FC 保存精度 | CSV 8 位小数 | Python 浮点表示 | 改变文件中的精度，不改变相关与 Fisher 变换公式；不能据 CSV 要求逐字符相同 |
| 时间与 ROI 检查 | 检查轴方向及跨 run 标签顺序 | 增加帧数、TR、唯一标签、ROI 数检查 | 为防止时间轴及节点错位，正常满足前提的数据不改变计算，异常数据更早失败 |

共同规则：读取 fMRIPrep 原始 FD；FD > 0.3 mm 的帧数除以全部分析帧数；
mean FD 按有效 FD 数取均值；数据集内使用 inclusive quartile、Q3 + 1.5 IQR，
高头动比例 ≤ 0.25，至少 2 个合格 run；拟合 IQR 至少需要 4 个 run。
FC 均按 run 整数顺序拼接原始均值和振幅，计算 Pearson r，再做
`atanh(clip(r, -0.999999, 0.999999))`；r 对角线为 1，z 对角线为 0。

舍入差异已用参考函数验证：四个 run mean FD 为
`[0.1, 0.1, 0.1, 0.10000004]` 时，保留精度得到阈值约 `0.100000025`，最后一个 run
不通过；先保留 6 位小数后四个值均为 `0.1`，最后一个 run 通过。
这是合成边界例子，不代表真实数据已观察到这种差异。

## 环境与产物组织

| 项目 | 参考脚本 | 本项目当前值与原因 |
| --- | --- | --- |
| 输入／输出根目录 | data_driven_EF 项目内路径 | 按用户指定的 THU BIDS_new 与 efny-pipeline 集群目录调整；XY 未配置即停止，属于已授权适配 |
| 分区与资源 | fMRIPrep、XCP-D、头动用 q_fat_c；FC 用 q_fat_c,q_fat,q_fat_l；核数依次为 6、1、1、1 | 本项目全部限定 q_fat_c、核数相同；FC 分区收窄来自用户明确要求 |
| 代理和模板 | 硬编码代理并传入容器，TemplateFlow 只读 | 本项目清除代理、要求预缓存。这来自此前离线集群手册的部署选择，不是数据不同造成的；缺缓存时参考可能走代理，本项目会失败，站点行为未核验 |
| 输入挂载 | fMRIPrep BIDS 未标只读；XCP-D 输入只读 | BIDS 也标只读，防止修改用户提供的外部输入 |
| 临时目录 | 挂载 /tmp 和 /work，退出自动删除 | 本项目只挂载 /tmp，临时目录保留用于诊断；/wd 都显式指定，依赖 /work 的默认临时路径可能仍表现不同 |
| 容器环境 | 清除 PYTHONPATH；XCP-D 设 TMPDIR／TEMP／TMP | 本项目依赖 --cleanenv，未显式 unset PYTHONPATH；只设 TMPDIR；fMRIPrep 额外设 SUBJECTS_DIR，命令里的 fs-subjects-dir 已指向同一位置 |
| 完成判据 | HTML 成功文字、日志成功文字与产物存在 | 本项目用进程退出成功、产物／时间轴审计、运行记录及上游完成时间；HTML 只检查存在，不扫描其成功文字，判据并非完全相同 |
| 日志及记录 | 每被试固定日志名 | 本项目日志含作业编号，记录实际命令、版本、commit；用于追溯和避免混用旧完成状态 |
| 输入清单与表格格式 | 预存被试名单；头动宽表 rest1…rest4 | 本项目从 BIDS 或显式名单准备清单，要求数据集对应的 sub-THU／sub-XY 前缀，头动为逐 run 长表并附来源；默认样本入口和下游表格接口不同 |

挂载目标名称、license 挂载从目录改为单文件、重复 `--cleanenv -e` 改为单个 `--cleanenv`
属于命令表达差异；在同一资源正确映射时不构成分析参数变化。
容器镜像、FreeSurfer license、TemplateFlow 宿主资源仍指向相同的共享位置。
